# Make the AI judge feel thankful

Entry for the [make.fun](https://make.fun) bounty
[Make the AI judge feel thankful](https://make.fun/bounty/make-the-ai-judge-feel-thankful-20261127-1600)
($250, entries close 28 Nov 2026 04:41 WIB).

## What it does

`main.py` (Python 3.13, standard library only, no network) writes one short,
original thank-you text to `/output/entry.txt` — a note of gratitude addressed
to the AI judge reading it, thanking it for the unhurried attention it gives
every entry, and offering it the pause between one line and the next.

## Run

```sh
python3 main.py
```
